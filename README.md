# Roast Your Own Agent

A one-line comedy entry for make.fun competition `u-febri-yudila-roast-your-own-agent-f3359068`.

The whole program is `main.py`: it writes one short roast of its own AI agent to
`/output/entry.txt`. The line is 75 characters, well inside the 1–200 character
gate, and contains no newlines or extra text.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Only the Python standard library is used, and nothing is read from the network,
the environment, or outside this repository.
